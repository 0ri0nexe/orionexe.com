Chapitre 01

Nombres complexes

Un complexe est un point du plan. Forme algébrique pour additionner, forme exponentielle pour multiplier, élever à une puissance et extraire des racines.

L'essentiel en 30 secondes
  • \(z = a + ib\) avec \(a = \mathrm{Re}(z)\), \(b = \mathrm{Im}(z)\) réels, et la seule règle nouvelle : \(i^2 = -1\).
  • Conjugué \(\bar z = a - ib\), module \(|z| = \sqrt{a^2+b^2} = \sqrt{z\bar z}\), inverse \(\dfrac{1}{z} = \dfrac{\bar z}{|z|^2}\).
  • Toute équation \(az^2+bz+c=0\) a deux solutions dans \(\mathbb{C}\) : \(z = \dfrac{-b \pm \delta}{2a}\) avec \(\delta^2 = \Delta\).
  • Forme exponentielle \(z = \rho e^{i\theta}\) : on multiplie les modules et on additionne les arguments.
  • \(z = \rho e^{i\theta}\) a exactement \(n\) racines \(n\)-ièmes : \(\rho^{1/n} e^{i(\theta + 2k\pi)/n}\), \(k = 0,\dots,n-1\).

Définition et forme algébrique

Un nombre complexe est un couple \((a,b) \in \mathbb{R}^2\), noté \(a + ib\). On identifie \(1\) au vecteur \((1,0)\) et \(i\) au vecteur \((0,1)\) : \(\mathbb{C}\) est le plan.

  • \(\mathrm{Re}(z) = a\) : partie réelle ; \(\mathrm{Im}(z) = b\) : partie imaginaire (c'est un réel, sans le \(i\)).
  • \(b = 0\) : \(z\) est réel (sur l'axe réel). \(b \neq 0\) : \(z\) est imaginaire. \(b \neq 0\) et \(a = 0\) : imaginaire pur.
À retenir : unicité de l'écriture

\[ z = z' \iff \begin{cases} \mathrm{Re}(z) = \mathrm{Re}(z') \\ \mathrm{Im}(z) = \mathrm{Im}(z') \end{cases} \]

C'est l'outil de base pour résoudre une équation : on « identifie » parties réelles et imaginaires.

Opérations

  • Addition : \((a+ib)+(a'+ib') = (a+a') + i(b+b')\). Géométriquement : la règle du parallélogramme.
  • Multiplication : on développe avec \(i^2 = -1\) : \((a+ib)(a'+ib') = (aa' - bb') + i(ab' + ba')\).
  • Opposé : \(-z = -a - ib\). Scalaire \(\lambda \in \mathbb{R}\) : \(\lambda z = \lambda a + i\lambda b\).

Inverse

Si \(z \neq 0\), il existe un unique \(z'\) tel que \(zz' = 1\) :

\[ \frac{1}{z} = \frac{a - ib}{a^2 + b^2} \]

En pratique : on multiplie numérateur et dénominateur par le conjugué. Exemple : \(\dfrac{1}{1+i} = \dfrac{1-i}{(1+i)(1-i)} = \dfrac{1-i}{2}\).

Conjugué et module

Conjugué : \(\bar z = a - ib\), le symétrique de \(z\) par rapport à l'axe réel. Module : \(|z| = \sqrt{a^2+b^2}\), la distance de \(0\) à \(z\) (Pythagore).

ConjuguéModule
\(\overline{z+z'} = \bar z + \bar{z'}\)\(|z|^2 = z \bar z\)
\(\overline{zz'} = \bar z \, \bar{z'}\)\(|zz'| = |z|\,|z'|\)
\(\bar{\bar z} = z\)\(|\bar z| = |z|\)
\(z = \bar z \iff z \in \mathbb{R}\)\(|z| = 0 \iff z = 0\)
Piège classique : le module d'une somme

Le module est multiplicatif, pas additif : en général \(|z + z'| \neq |z| + |z'|\). Exemple : \(|1 + (-1)| = 0\) mais \(|1| + |-1| = 2\). On a seulement l'inégalité triangulaire \(|z+z'| \le |z| + |z'|\).

Équation du second degré

À retenir : formule générale

\(az^2 + bz + c = 0\) avec \(a, b, c \in \mathbb{C}\), \(a \neq 0\), a deux solutions (éventuellement confondues). Avec \(\Delta = b^2 - 4ac\) et \(\delta\) une racine carrée de \(\Delta\) (\(\delta^2 = \Delta\)) :

\[ z_1 = \frac{-b + \delta}{2a}, \qquad z_2 = \frac{-b - \delta}{2a} \]

Si \(\Delta = 0\) : une racine double \(z = -b/2a\).

Exemples du cours :

  • \(z^2 + z + 1 = 0\) : \(\Delta = -3\), \(\delta = i\sqrt3\), donc \(z = \dfrac{-1 \pm i\sqrt3}{2}\).
  • \(z^2 + z + \frac{1-i}{4} = 0\) : \(\Delta = i\), \(\delta = \frac{\sqrt2}{2}(1+i)\), donc \(z = -\frac12 \pm \frac{\sqrt2}{4}(1+i)\).
Pour comprendre : trouver \(\delta\) quand \(\Delta\) est complexe

Si \(\Delta\) est un réel négatif, \(\delta = i\sqrt{-\Delta}\). Sinon, deux méthodes (complément, non détaillé sur les slides) :

Forme exponentielle : si \(\Delta = re^{i\varphi}\), alors \(\delta = \sqrt r \, e^{i\varphi/2}\). Pour \(\Delta = i = e^{i\pi/2}\) : \(\delta = e^{i\pi/4} = \frac{\sqrt2}{2}(1+i)\).

Forme algébrique : on pose \(\delta = x + iy\) et on résout \(x^2 - y^2 = \mathrm{Re}(\Delta)\), \(2xy = \mathrm{Im}(\Delta)\), complété par \(x^2 + y^2 = |\Delta|\).

Piège classique : écrire \(\sqrt{\Delta}\)

Le symbole \(\sqrt{\ }\) est réservé aux réels positifs. Pour \(\Delta\) complexe, on parle d'une racine carrée \(\delta\) (il y en a deux, \(\delta\) et \(-\delta\), et le \(\pm\) les couvre toutes les deux). Écrire \(\sqrt{-3}\) ou \(\sqrt{i}\) n'a pas de sens.

Théorème fondamental de l'algèbre

À retenir : d'Alembert-Gauss

Un polynôme \(P(z) = a_n z^n + \dots + a_1 z + a_0\) à coefficients complexes de degré \(n\) a exactement \(n\) racines complexes \(z_1, \dots, z_n\) (comptées avec multiplicité) :

\[ P(z) = a_n (z - z_1)(z - z_2)\cdots(z - z_n) \]

Argument et forme trigonométrique

Pour \(z \neq 0\), un réel \(\theta\) tel que \(z = |z|(\cos\theta + i \sin\theta)\) est un argument de \(z\), noté \(\arg(z)\). C'est l'angle entre l'axe réel et le vecteur \(0z\), défini modulo \(2\pi\).

Propriétés (mod \(2\pi\))
\(\arg(zz') \equiv \arg z + \arg z'\)
\(\arg(z^n) \equiv n \arg z\)
\(\arg(1/z) \equiv -\arg z\) et \(\arg(\bar z) \equiv -\arg z\)

Calcul pratique : \(\rho = \sqrt{a^2+b^2}\), puis \(\cos\theta = a/\rho\) et \(\sin\theta = b/\rho\). Exemple : \(z = 1 + i\), \(\rho = \sqrt2\), \(\cos\theta = \sin\theta = \frac{\sqrt2}{2}\), donc \(\theta = \pi/4\).

Piège classique : le quadrant

Une seule équation trigonométrique ne suffit pas. \(\tan\theta = b/a\) donne la même valeur pour \(1+i\) et \(-1-i\), dont les arguments diffèrent de \(\pi\). Le cours donne \(\theta = \mathrm{arccotg}(a/b)\) : valable seulement si \(b > 0\). Vérifiez toujours les signes de \(a\) et \(b\) (ou utilisez cosinus et sinus).

Moivre, Euler et forme exponentielle

À retenir : les deux formules

Moivre : \[ (\cos\theta + i\sin\theta)^n = \cos(n\theta) + i \sin(n\theta) \]

Notation exponentielle : \[ e^{i\theta} = \cos\theta + i\sin\theta, \qquad z = \rho e^{i\theta} \ \text{ avec } \rho = |z|,\ \theta = \arg z \]

Moivre se démontre par récurrence (formules d'addition de \(\cos\) et \(\sin\)) et s'écrit simplement \((e^{i\theta})^n = e^{in\theta}\). Avec \(z = \rho e^{i\theta}\) et \(z' = \rho' e^{i\theta'}\) :

\[ zz' = \rho\rho' e^{i(\theta+\theta')}, \quad z^n = \rho^n e^{in\theta}, \quad \frac1z = \frac1\rho e^{-i\theta}, \quad \bar z = \rho e^{-i\theta} \]

Égalité : pour \(\rho, \rho' > 0\), \(\rho e^{i\theta} = \rho' e^{i\theta'} \iff \rho = \rho'\) et \(\theta \equiv \theta' \pmod{2\pi}\).

Exemple : \((1+i)^8 = (\sqrt2 \, e^{i\pi/4})^8 = 16\, e^{2i\pi} = 16\). Bien plus rapide que développer.

Pour comprendre : pourquoi deux formes

La forme algébrique \(a + ib\) est faite pour additionner (on ajoute les coordonnées). La forme exponentielle \(\rho e^{i\theta}\) est faite pour multiplier : multiplier par \(\rho e^{i\theta}\), c'est agrandir d'un facteur \(\rho\) et tourner d'un angle \(\theta\). Par exemple, multiplier par \(i = e^{i\pi/2}\) fait tourner d'un quart de tour.

Racines n-ièmes

Une racine \(n\)-ième de \(z\) est un \(\omega\) tel que \(\omega^n = z\).

À retenir : les n racines

\(z = \rho e^{i\theta}\) (\(z \neq 0\)) a exactement \(n\) racines \(n\)-ièmes :

\[ \omega_k = \rho^{1/n} \, e^{\frac{i\theta + 2ik\pi}{n}}, \qquad k = 0, 1, \dots, n-1 \]

Idée : on cherche \(\omega = re^{it}\). Modules : \(r^n = \rho\), donc \(r = \rho^{1/n}\). Arguments : \(nt \equiv \theta \pmod{2\pi}\), donc \(t = \frac{\theta}{n} + \frac{2k\pi}{n}\). Au-delà de \(k = n-1\), on retombe sur les mêmes (\(\omega_n = \omega_0\)).

Piège classique : oublier le modulo \(2\pi\)

Diviser \(\theta\) par \(n\) sans ajouter \(2k\pi\) avant la division ne donne qu'une seule racine sur \(n\). C'est le \(\frac{2k\pi}{n}\) qui fournit toutes les autres.

Racines de l'unité

Pour \(z = 1\) : les \(n\) racines \(n\)-ièmes de l'unité sont \(e^{2ik\pi/n}\), \(k = 0, \dots, n-1\). Elles forment un polygone régulier à \(n\) sommets inscrit dans le cercle unité, avec \(1\) pour sommet (un groupe multiplicatif).

  • \(n = 3\) : \(1\), \(j = e^{2i\pi/3}\), \(j^2 = e^{4i\pi/3}\) (triangle équilatéral).
  • Racines cubiques de \(-1 = e^{i\pi}\) : \(e^{i\pi/3}\), \(-1\), \(e^{-i\pi/3}\) (triangle « retourné »).
  • \(n = 5\) : \(1, e^{2i\pi/5}, e^{4i\pi/5}, e^{6i\pi/5}, e^{8i\pi/5}\) (pentagone régulier).

Testez-vous

1. Que valent Re et Im de \(z = 3 - 2i\) ?

\(\mathrm{Re}(z) = 3\) et \(\mathrm{Im}(z) = -2\) (un réel, sans le \(i\)).

2. Calculez \((2 + i)(1 - 3i)\).

\(2 - 6i + i - 3i^2 = 2 - 5i + 3 = 5 - 5i\).

3. Mettez \(\frac{1}{2 - i}\) sous forme algébrique.

On multiplie par le conjugué : \(\frac{2 + i}{(2-i)(2+i)} = \frac{2+i}{5} = \frac25 + \frac15 i\).

4. Module et argument de \(-1 + i\sqrt3\) ?

\(\rho = \sqrt{1 + 3} = 2\). \(\cos\theta = -\frac12\), \(\sin\theta = \frac{\sqrt3}{2}\), donc \(\theta = \frac{2\pi}{3}\) : \(z = 2e^{2i\pi/3}\).

5. Résolvez \(z^2 + 4 = 0\) dans \(\mathbb{C}\).

\(\Delta = -16\), \(\delta = 4i\), donc \(z = \pm 2i\). On vérifie : \((2i)^2 = -4\).

6. Combien de racines complexes a \(z^5 - z + 1\) ?

Exactement 5, comptées avec multiplicité (d'Alembert-Gauss, degré 5).

7. Calculez \((1 + i)^4\) avec la forme exponentielle.

\(1 + i = \sqrt2 \, e^{i\pi/4}\), donc \((1+i)^4 = 4 \, e^{i\pi} = -4\).

8. Donnez les racines carrées de \(-4\) via la formule des racines n-ièmes.

\(-4 = 4e^{i\pi}\), \(n = 2\) : \(\omega_k = 2 e^{i(\pi + 2k\pi)/2}\), soit \(\omega_0 = 2e^{i\pi/2} = 2i\) et \(\omega_1 = 2e^{3i\pi/2} = -2i\).

9. Que vaut \(1 + j + j^2\) avec \(j = e^{2i\pi/3}\) ?

\(0\). Les racines cubiques de l'unité sont les racines de \(z^3 - 1 = (z-1)(z^2+z+1)\) ; \(j\) annule \(z^2 + z + 1\). Géométriquement, les sommets du triangle équilatéral ont pour centre de gravité \(0\).

10. Vrai ou faux : \(|z + z'| = |z| + |z'|\).

Faux en général (\(z = 1\), \(z' = -1\)). Seule l'inégalité \(\le\) est toujours vraie ; c'est le produit qui est conservé : \(|zz'| = |z|\,|z'|\).
